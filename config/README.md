# 配置约定

[设备示例](motors.example.yaml) 和 [安全示例](safety.example.yaml) 是待填写的结构，不是可执行真机配置。
当前没有配置加载器或控制程序，所以 `hardware_enabled: false` 本身不构成已实现的软件保护。

数值须有设备/固件依据、单位、坐标定义与验证日期；未知值保留 `null`。不复制参考机械臂或旧仓库的默认参数。
CAN bit/s 与串口 baud 分开；ID 格式在实际加载器中显式约定，拒绝歧义转换。
方向、零点及减速比决定电机状态到关节状态的转换，不能只改一个比例而忽略速度和力矩的定义。
真实配置保存在本地 `*.local.yaml`（忽略提交）；公开实验通过去敏后的参数快照保留可复现性。
未来加载器必须在打开总线前拒绝缺失限制、非有限数值、上下界反转和错误设备适配。
