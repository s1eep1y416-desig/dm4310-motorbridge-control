## 6. D 五道思考题

1. Controller、Motor、MotorState 各自负责什么？为什么一个对象不能代替另外两个？
   - 你的回答（2026-10-10）：Controller 负责管理连接和通信串口，请求设备反馈等；Motor 是某个电机，负责接收指令和动作；MotorState 是电机的状态，是某一时刻的快照。
   - 正确答案与审查：`Controller` 管理一条通信连接，负责建立连接、添加设备和轮询反馈；`Motor` 是某一台电机的操作句柄，负责请求反馈、发送该电机的命令和读取状态；`MotorState` 只是一次读取到的一组状态数据，不负责连接或发命令。三者分别承担连接层、设备操作层和数据层职责，所以不能互相代替。你的方向基本正确，但 `request_feedback()` 属于 `Motor`；当前 `MotorState` 没有 timestamp 或 sequence，不能单凭非空对象断定它是刚收到的新快照。
2. request_feedback、poll_feedback_once 和 get_state 各做哪一步？这三步与本次离线程序有什么区别？
   - 你的回答（2026-10-10）：`request_feedback` 是请求电机反馈；`poll_feedback` 是轮询；`get_state` 是获取状态；与本次离线程序的区别不知道。
   - 正确答案与审查：`motor.request_feedback()` 向该电机发出反馈请求；`controller.poll_feedback_once()` 让通信连接轮询并处理一次反馈；`motor.get_state()` 返回当前可读取的 `MotorState` 或 `None`。本次离线程序不创建 Controller/Motor，不请求、轮询或读取真实设备，只把手工构造的 `MotorState` / `None` 转换成文字。你的前三步方向正确，遗漏了调用对象和离线程序的区别。
3. get_state 返回 None 与返回 pos=0、vel=0 的 MotorState，有什么不同？你的程序怎样体现？
   - 你的回答（2026-10-10）：`None` 表示未收到反馈；0 是位置或者速度为 0；程序用 `if state is None`。
   - 正确答案与审查：`None` 表示没有可返回的状态；非空且 `pos=0、vel=0` 表示已经有一个状态对象，只是位置和速度字段恰好为零。程序应先用 `if state is None` 分支处理无状态，避免访问空对象属性；否则再读取 `pos`、`vel`。你的核心区别正确；首次代码中的 `"None"` 提示已在最终版本改为“尚未收到反馈”。
4. 第三组输入的位置换算成多少度，速度负号表示什么？本次能否由此推断真实电机的转向？
   - 你的回答（2026-10-10）：不知道。
   - 正确答案与审查：`π/2 rad × 180/π = 90°`。速度 `-0.5 rad/s` 的负号表示它相对于当前数学/设备坐标约定沿负方向变化。合成数据只是人为填入的数值，而且真实电机的方向符号、安装方向、减速器和关节映射都未核对，因此不能据此推断真实电机朝哪个物理方向转动。
5. 如果状态对象非空，你是否已经知道它是刚收到的反馈？当前数据类还缺什么信息？
   - 你的回答（2026-10-10）：不知道。
   - 正确答案与审查：不知道。`MotorState` 非空只说明 SDK 当前有一组可返回的数据，可能是刚更新的数据，也可能是缓存中的旧数据。当前数据类缺少接收时间戳、序列号或明确的新帧标志；还需要在可验证的接收边界记录时间或序号，才能判断反馈是否新鲜。

## 10. 学到的理论与遇到的问题

2026-10-11 用户独立复述：

1. “Controller 就是管连接和通信的，像发请求、轮询这些。Motor 是具体电机的操作入口，负责对某台电机下命令。MotorState 就是某一刻的状态快照，存 pos、vel 这些。三个一个是管通信，一个是操作设备，一个是存数据，所以不能一个顶三个，不然耦合太高，也不好测试。”
2. “request_feedback 是发请求，poll_feedback_once 是收一次，get_state 是拿当前状态。本次离线程序这三步都不做，只是自己造 MotorState，然后格式化显示。所以离线程序只验证显示逻辑，不验证真实通信。”
3. “返回 None 就是还没收到反馈、没有可用状态；返回 pos=0、vel=0 是已经有一个状态对象，只是位置和速度刚好是 0。程序里先判断 if state is None，是 None 就返回‘尚未收到反馈’；不是 None 才去读 pos 和 vel。”
4. “MotorState 非空不代表它就是刚收到的反馈，它可能是缓存、旧状态，也可能是手动造出来的。当前数据类还缺时间戳、接收时间、序号或帧计数、是否新帧、来源设备 ID 这些，所以没法判断它新不新、从哪来。”

复核结果：第 2 段通过；第 3 段对 None 与零值的区分正确；第 4 段准确补充了非空对象可能是缓存旧值或手工构造数据，并给出了时间戳、序号、帧计数或新帧标志等新鲜度证据，因此反馈新鲜度通过。第 1 段的分层和解耦理由正确，但方法归属仍需精确：`request_feedback()` 属于 `Motor`，Controller 负责连接和 `poll_feedback_once()` 等通信管理。
