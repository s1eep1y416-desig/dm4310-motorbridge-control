## 6. D 思考题（先回答，再评价）

1. `Controller.from_dm_serial(serial_port, baud)` 的两个参数分别表示什么？成功时返回的对象负责什么？
   - 你的回答（2026-10-11）：`controller` 两个参数对应设备串口和波特率；返回成功负责设备通信、注册电机信息、启动和关闭电机等。
   - 审查：通过。`serial_port` 是设备串口路径，`baud` 是串口波特率；返回的 `Controller` 负责通信连接、添加电机及轮询等管理工作。为避免和使能混淆，本课将“启动、关闭”准确表述为连接和资源管理；使能/失能另课学习。
2. `add_damiao_motor()` 的三个参数分别是什么？它与“修改电机内部 ID”有什么区别？
   - 你的回答（2026-10-11）：发送指令、接受指令、电机型号；修改电机 ID 要用 `dm_set_motor_id` 将电机 ID 写入寄存器。
   - 审查：核心理解通过并修正术语。三个参数分别是作为命令目标的 `motor_id`、反馈标识 `feedback_id` 和 SDK 型号键 `model`；`add_damiao_motor()` 只在 Controller 上登记 Motor 句柄，不修改真实电机 ID。当前 MotorBridge 0.5.6 Python 源码未发现 `dm_set_motor_id`；其 CLI 对达妙 ID 使用独立寄存器写入流程。修改 ID 不属于本课必考内容，因此接口名称修正不扣分，也不得在本任务执行。
3. 为什么 `/dev/ttyACM0`、`921600` 或历史代码中的 `0x01` 不能直接写成当前设备的已确认值？
   - 你的回答（2026-10-11）：默认值不等于真实设备值；`/dev/ttyACM0` 为 Linux 动态分配，波特率取决于硬件适配器，电机 ID 可以人为分配。
   - 审查：通过。默认值、历史示例和当前设备事实属于不同证据；可配置不代表已经知道当前配置。
4. 为什么今天可以对文件做 `compile()` 检查，却不能调用 `open_dm_serial()`？
   - 你的回答（2026-10-11）：一个是纯语法检查，一个会调用真实设备。
   - 审查：通过。`compile()` 只解析源码文字；`open_dm_serial()` 会进入 SDK/ABI 并尝试打开真实通信入口。
