# 实验与证据

当前没有新实验、测量数据或硬件结果。
实验开始时使用 [实验模板](../templates/experiment-report.md)，按任务创建对应 single-motor、multi-motor、ros2、kinematics 或 dynamics 子目录。
保存原始数据、版本、参数快照、脚本和分析；明确数据来自真实传感器、仿真还是合成测试序列。
合成状态只能验证软件逻辑，不能标成电机已运动、输出准确或急停有效。
先冻结测量目标、单位、条件、目标数值、允许偏差和依据；结束后填实际结果。
数据量增大后记录校验值及受控存储位置，不让大体积 bag/CSV 无限制进入 Git；本次不预设丢弃实验数据的全局忽略规则。
