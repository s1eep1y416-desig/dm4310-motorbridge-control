# 可复用模板

模板不是任务结果。填写真实资料后保存到对应目录，保留任务 ID、日期、版本与相对链接。

- [理论笔记](theory-note.md)
- [工程笔记](engineering-note.md)
- [实验报告](experiment-report.md)
- [故障案例](troubleshooting-case.md)
- [代码审查](code-review.md)
- [每日任务](daily-task.md)
- [阶段考核](stage-assessment.md)
- [Architecture Decision Record](adr.md)

按 AGENTS 原文分类：通用理论归 knowledge/，项目设计归 engineering/，实验归 experiments/，故障归 troubleshooting/，学习过程归 learning/daily/，考核归 learning/assessments/。各类通过相对链接关联；不强制将理论和设计合并。
