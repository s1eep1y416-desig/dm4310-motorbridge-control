# MotorBridge 应用接口：第一课设计

日期：2026-10-10。关联 [S1-001](../../learning/daily/2026-10-10-S1-001.md) 与 [入门讲义](../../knowledge/motor-control/motorbridge.md)。这是实现前确定的设计要求；`001_motorbridge_intro.py` 已按要求修正并通过 [离线代码复核](../../learning/reviews/2026-10-10-S1-001-review.md)，以下接口要求不变。

## 先完成一个能看到输出的小功能

输入是 MotorBridge 的 `MotorState` 或 `None`，输出是一行状态文字。调用者负责提供状态，显示函数只解释输入：

```text
本课手工构造的 MotorState / None
             ↓
      describe_state(state)
             ↓
         一行状态文字
```

日后可把输入换成经过有效性检查的实际 SDK 反馈。本课不建立完整适配器、Fake 总线或设备管理器。

## 文件和接口

由学习者在 `examples/S1_can_and_id/001_motorbridge_intro.py` 实现。目录保留 AGENTS 原文名称；课程入口已改为 MotorBridge，详见 [路线调整](../design-decisions/ADR-0002-motorbridge-first.md)。

```python
def describe_state(state: MotorState | None) -> str:
    ...  # 学习者独立实现
```

要求：

- 输入为 `None`：返回 `尚未收到反馈`，不读取其属性。
- 有状态：至少显示 `pos` 的 rad 值、换算的 deg 值和 `vel` 的 rad/s 值；显示保留三位小数，标签明确。
- 函数返回字符串，打印由调用者处理；不修改输入对象，不读文件或打开通信连接。
- 仅支持以上两种输入；本课不增加任意字典适配、自动重连等扩展。
- `main()` 中构造本课三组输入并打印；用 `if __name__ == "__main__":` 保护入口。
- 终端开头明确写 `合成数据，未连接电机`。不把 `torq` 字段显示成已经确认的关节力矩。

## 输入约定与检查

三组输入由学习者创建：

| 场景 | pos / vel | 应观察的性质 |
|---|---|---|
| 无反馈 | 输入 `None` | 有明确提示，程序不崩溃 |
| 静止样本 | `0.0` rad / `0.0` rad/s | 位置和速度均显示零值及各自单位 |
| 非零样本 | `π/2` rad / `-0.5` rad/s | 角度转换正确，速度负号保留 |

两份 `MotorState` 的其余字段均使用 0 作为本课数据占位：它们只是人为构造的数字，不是建议设备 ID、温度或正常状态码。无需推断这些占位值的设备含义。

先手算第三行角度，再与程序显示比较；在任务卡记录预期和实际结果。三组输入足以检查本课目标，无需第一天建立整套测试框架。未来反馈新鲜度与失败路径有单独任务。
