# ADR-0002：从 MotorBridge 应用开始学习

日期：2026-10-10。状态：Accepted（用户明确要求“直接从 motorbridge 开始”）；这不是学习验收结果。

## 背景与决定

原 S1-001 是环境与设备证据卡，后接独立 CAN/ID 学习。用户反馈偏底层，并明确要求从 MotorBridge 开始。因此以 SDK 对象、状态读取、单电机控制作为学习入口，通信细节结合接口和故障讲解。

保留 S1-001 身份，将其范围修订为“MotorBridge 入门与状态显示”；当天任务卡就地修订。修订前只有助手材料，没有学习者提交或回答，未覆盖学习成果。旧设备资料设计保留作首次硬件准备的参考，不再作为首日必交项。

S1-002 改为 SDK 连接入口与设备参数，S1-003 继续反馈机制，S1-004/005 处理读取封装与退出。S2 聚焦位置、速度和 MIT 控制，之后继续 ROS 2、双关节、运动学与动力学。38 个任务 ID 和 S1–S8 框架保留，不把任何任务预标完成。

## 范围和取舍

- 沿用 AGENTS 目录，`examples/S1_can_and_id/` 不因教学入口变化而改名。
- 第一课使用现有 SDK 环境中的实际 `MotorState` 数据类型，练习代码保存于新仓库；先不引入跨环境安装问题。
- 环境/设备资料随使用补齐；首次真实连接前仍需对应设备条件，真实运动另按授权范围执行。
- 第一课不要求自行实现 CAN 驱动或理解 C ABI；必要 ID、单位、反馈有效性和退出行为仍在对应 SDK 任务学习与验收。
- 当前变更只涉及学习材料、路线及自动化提示词。没有实现学习者程序、安装依赖、运行硬件或执行 Git 提交/推送。

## 验证与回退

已核对本机 SDK 0.5.6 的类、方法和状态字段；阻止本地库加载的条件下，导入与构造 `MotorState` 成功。文档修改完成后运行仓库检查，核对导航、38 个任务身份及定时提示词一致性；不以这些检查代替用户学习验收。

本次修改前的 Markdown、Git 差异和自动化配置已在聊天工作目录 `work/motorbridge-first/` 备份。需要调整时在现有任务 ID 上记录新决定；有学习者内容后不得用旧备份覆盖它。
